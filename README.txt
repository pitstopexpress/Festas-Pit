PITSTOP EVENTOS - SISTEMA DE CONSIGNAÇÃO

Como usar:
1. Abra index.html no navegador.
2. O app funciona no celular e computador.
3. Os dados ficam salvos no navegador via localStorage.
4. Depois, troque os dados em firebase-config.example.js pelos dados reais do Firebase.
5. Para publicar: envie a pasta para o GitHub e conecte no Netlify.

Funções prontas:
- Dashboard desktop
- Layout responsivo mobile
- Cadastro de eventos
- Produtos enviados
- Retorno/consumo automático
- Patrimônio emprestado
- Fechamento financeiro
- Nota A4/PDF via imprimir
- Nota térmica via imprimir
- Enviar resumo pelo WhatsApp
- Produtos, clientes, patrimônio, financeiro e configurações
